## 一、遊戲概念

玩家先估算每週要存多少錢，接著用六週時間為校園園遊會做準備。每週先看事件，再選擇任務並把錢分配到動物卡收藏基金、點心飲料和下週可用的錢包。六週結束時，遊戲會顯示收藏結果和每週決策紀錄；尚未達標時也會顯示差額，讓玩家檢視策略後重新挑戰。

## 二、學習目標

### 核心學習目標

玩家能根據每週可用收入、儲蓄目標和當週事件，規劃儲蓄進度，並判斷自己是否能在期限內達標。

### 延伸能力

- 比較任務收入、目標儲蓄和想立即購買的點心飲料之間的取捨。
- 區分收藏基金、當週消費和留在錢包的現金。
- 發生收入或支出變動時，重新計算可用金額並調整計畫。
- 說明當週分配方式的理由，而不只看最後有沒有達標。

### 學習目標與遊戲證據的對應

| 學習目標 | 玩家行動 | 規則與狀態變化 | 可觀察證據 |
| --- | --- | --- | --- |
| 規劃儲蓄進度 | 設定每週計畫，選任務後安排實際存款 | 六週後基金達 NT$290 可兌換一套收藏 | 起始計畫、每週選擇的任務、實際存款與基金進度 |
| 比較目標與即時消費 | 決定是否購買點心或飲料 | 消費提供當下享受，但不增加收藏基金 | 消費金額、儲蓄金額與期末差額 |
| 因應變動 | 看見事件後，依目前條件安排本週金額 | 事件可能增加收入或帶來臨時支出 | 每週事件、實際存款與錢包結餘 |
| 解釋選擇 | 根據結算紀錄回答反思問題 | 結算顯示選擇、事件及金額結果 | 玩家口頭或課後說明的決策理由 |

遊戲分數、完成回合數或是否收齊卡片不能單獨證明玩家已學會理財。若要判斷概念理解，還要看玩家能否解釋金額變化及其選擇理由；保留與遷移能力則需要後續延遲或新情境任務才能評估。

## 三、核心遊戲循環

1. 遊戲開始時，設定預計每週存款，查看六週預估金額與目標差距。
2. 每週查看錢包、收藏基金與先揭露的事件。
3. 從三個任務中比較報酬及材料費，選擇一項。
4. 決定是否購買點心或飲料，再安排存款與錢包留存。
5. 確認本週安排，查看實際存款、餘額、目標差額及剩餘週數的平均需求。
6. 進入下一週；六週期滿後查看結果和決策紀錄。
7. 未達標時檢視差額與紀錄，再重新規劃並重玩。

## 四、主要玩法與規則

### 每週收入

- 起始錢包為 NT$0；每週固定零用錢為 NT$30。
- 任務報酬為 NT$10、NT$20 或 NT$25，材料費分別為 NT$0、NT$5 或 NT$5。
- 事件卡可帶來額外收入或臨時支出。
- 所有金額使用新臺幣整數，不使用小數。
- MVP 中任務以選項與金額呈現，不包含另外的任務小遊戲。

### 金錢分配

每週可用金額由上週留存的錢包餘額、固定零用錢、任務報酬及事件影響構成。玩家可以：

- 存入動物卡收藏基金。
- 購買一項點心或飲料，獲得即時享受；這筆消費不會推進收藏進度。
- 將沒有分配的金額留在錢包，帶到下週繼續使用。

結算時顯示金額關係，避免把基金、消費與留存現金混為一談：

可用金額（扣點心前）= 錢包留存 + 固定零用錢 + 事件收支 + 任務報酬 − 材料費

本週結餘 = 可用金額 − 存入收藏基金 − 點心飲料消費

### 收藏目標與期限

- 目標是一套固定的動物／角色卡收藏，價格與目標金額清楚。
- 收藏目標：NT$290；六張卡片價格分別為 NT$35、40、45、50、55、65。
- 期限：六週；達標後在期末兌換整套卡片。
- 六週期滿仍未達標時，呈現距離目標的金額差、每週收入來源、存款、消費、錢包留存和事件卡。
- 玩家可以依照紀錄重新規劃並重玩。

PDF 第 102 頁曾以 NT$270 作為企劃初始假設；第 113 頁的實際範例改為六張卡合計 NT$290。此 MVP 採用後者，兩者都仍需目標玩家試玩。

### 事件與任務

- 每週有多個任務選項，收入與條件不同。
- MVP 事件涵蓋收入變化與突發支出。
- 玩家先設定六週的每週平均存款計畫；每週事件在當週分配前揭露，玩家可依已知條件調整本週安排。
- MVP 的事件順序先固定，確保每次試玩都能比較策略；平衡完成後再決定是否加入隨機排列。

## 五、節奏與回饋

| 階段 | 教學支援 |
| --- | --- |
| 第 1–2 週 | 說明錢包、零用錢、任務收入與收藏基金的差異；事件一次只改變一項條件 |
| 第 3–4 週 | 出現臨時支出或額外收入，引導玩家重新計算可分配金額 |
| 第 5–6 週 | 強調期限與累積進度，讓玩家自行調整任務、儲蓄、消費與留存 |
| 回合結算 | 顯示實際算式，說明事件如何改變可用金額，以及本週決策對收藏進度的影響 |
| 六週結束 | 顯示是否達標、差額和決策紀錄，提供重玩機會與反思問題 |

回饋要回答三件事：發生了什麼、為什麼金額或進度改變、下一週可以如何調整。失敗只呈現可用的資訊，不用羞辱或扣除參與資格的懲罰。

## 六、介面與美術方向

- 視覺主題：校園園遊會、可愛 2D 動物卡、輕鬆明亮的攤位場景。
- 主要畫面直接呈現當週計畫、錢包金額、收藏進度與事件卡。
- 動物卡收藏區顯示已收集項目與尚未達到的目標；金額計算與說明文字保持清楚易讀。
- 不加入獨立首頁；遊戲載入後直接顯示第一週的可玩畫面及簡短操作提示。
- 先以桌面瀏覽器為主要版面，同時規劃窄螢幕可用的垂直排列。

## 八、MVP 範圍與完成條件

MVP 要先完成一個從第一週玩到結算的核心循環，不先擴充大量任務、商店或劇情。

### MVP 必要功能

- 六週單人遊戲流程；每週選擇一項任務。
- 固定 NT$30 零用錢、NT$10–25 任務報酬和 NT$290 收藏目標作初始試玩數值。
- 遊戲開始設定每週存款目標；每週事件在當週分配前揭露。
- 儲蓄、點心飲料消費與錢包留存使用整數金額並正確結算。
- 上週未分配的錢包金額帶到下一週。
- 收藏進度能即時反映存款，點心消費不會推進收藏目標。
- 每週結果顯示收入、事件、儲蓄、消費、留存和清楚的解釋性回饋。
- 期限內達標時完成收藏；未達標時顯示差額和六週決策紀錄，並能重玩。
- 使用選定的 Kenney 動物插圖與 Phaser 繪製的介面。

### MVP 驗收問題

1. 玩家能否說出本週可用金額由哪些來源組成？
2. 玩家能否分辨存入收藏基金、購買點心和留在錢包的金額？
3. 事件卡揭露後，玩家能否看懂改變的是收入還是支出？
4. 結算回饋能否讓玩家指出自己的選擇如何影響目標差額？
5. 未達標時，玩家能否利用決策紀錄提出一個可行的新策略？

## 九、實作步驟與迭代順序

依照「素材挑選 → MVP → 分階段迭代」執行。

### 步驟 1：完成素材挑選（已完成）

- 查看 Animal Pack Remastered、UI Pack、Board Game Pack 的官方預覽與實際檔案。
- 以動物卡插圖為主，挑出整套畫風一致的 2D 素材。
- 核對每個選用套件的官方授權與包內授權檔。
- 將六張選中的圖檔加入專案、建立素材來源紀錄並更新 manifest。
- 確認圖檔尺寸、檔名和 Phaser 4 載入方式。

### 步驟 2：製作可玩 MVP（已完成，待玩家試玩）

- 建立第一週直接開玩的主畫面與六週進度。
- 實作起始存款計畫、每週事件揭露、任務選擇、預算分配和每週結算。
- 實作錢包結轉、收藏基金累積、目標達成與期限未達標流程。
- 加入回合解釋、決策紀錄、重玩與基本窄螢幕版面。
- 先用下表標示為初始假設的數值；用試玩結果調整前，不把它們描述成已驗證的平衡值。

### 步驟 3：迭代一 — 規則可讀性與數值平衡

- 觀察玩家是否看懂錢包、基金、收入、消費和事件的差別。
- 檢查低報酬與高報酬任務是否各有選擇理由。
- 調整任務報酬、事件幅度、點心價格和 NT$290 目標，避免目標無論怎麼選都必然成功或必然失敗。
- 檢查事件後的修正是否真的影響結果，並讓玩家看懂差額。

### 步驟 4：迭代二 — 教學支援與反思

- 依試玩卡點補上金額算式、預算提示或分步提示。
- 讓玩家在回合或結束時說明自己如何安排，以及事件改變了什麼。
- 視目標加入新條件的短遷移題；使用未出現在遊戲中的數字與情境。
- 將遊戲內行為紀錄與玩家實際解釋分開整理，不把完成度當成學習成效。

### 步驟 5：迭代三 — 內容、介面與無障礙

- 在核心規則穩定後增加新任務、事件和動物卡。
- 改善鍵盤操作、文字對比、按鈕大小、提示和窄螢幕排列。
- 依需求加入音效或收藏動畫；動畫不遮住計算與回饋。
- 最後再調整裝飾、美術細節和回合節奏。

## 十一、評估與試玩紀錄

首輪試玩聚焦在「玩家是否能理解並運用預算規則」，可記錄：

- 每週選了哪種報酬的任務。
- 面對每週先揭露的事件，玩家如何調整原先的平均存款計畫。
- 玩家是否會把所有可用金額都算進基金，或保留錢包餘額。
- 玩家對即時消費、累積儲蓄和最後差額的說明。
- 玩家重玩時是否調整策略，以及能否說出調整原因。

停留時間、操作次數與是否破關只表示參與或遊戲內表現。若要驗證學習，需另外看玩家能否正確解釋金額變化，或在未見過的新數字與新事件中規劃預算；要宣稱長期保留，還需安排延後評量。
