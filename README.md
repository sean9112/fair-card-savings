# 園遊會卡片收藏家

一款給國小高年級玩家的六週儲蓄規劃遊戲。玩家比較任務報酬與材料費，因應每週事件，在點心消費、收藏基金和錢包餘額之間做選擇，並在結束時回顧自己的決策。

遊戲使用 Phaser 4、TypeScript 和 Vite。六張動物卡合計 NT$290；目前數值屬於 MVP 試玩假設。

## 開始遊玩

[開啟 GitHub Pages 遊戲](https://sean9112.github.io/fair-card-savings/)

## 本機開發

需要 Node.js 22.12 以上與 npm：

    npm ci
    npm run dev

依照終端機顯示的網址開啟遊戲。執行正式建置：

    npm run build

推送至 main 後，GitHub Actions 會建置並部署 GitHub Pages。

## 學習紀錄

玩家開始遊戲時可選擇是否傳送匿名紀錄。若同意，每週結算會送出任務、消費、存款等資料；遊戲結束時送出結果，並可選填反思。請不要在反思中填入個人資料。

資料送至 Google Apps Script 網頁應用程式。由於跨網域請求無法確認伺服器的回應，送出不代表資料已成功寫入，需由教師查看試算表。為應對中斷，紀錄可能保存在瀏覽器的本機儲存空間；再次同意紀錄或網路恢復時會重試七天內的紀錄，接收端用事件 ID 避免重複。清除網站資料會移除本機紀錄。

網址會包含在公開的遊戲程式中，不是密鑰；持有網址者可能提交資料。正式收集敏感資料或用於高風險評量前，應採用具身分驗證和防濫用機制的後端。

開發時可設定 `VITE_EVIDENCE_URL` 指向本機模擬接收端；設為空字串可停用送出，避免試玩資料進入正式試算表。
